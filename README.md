# EREKE M&D — онлайн дүкен (демо)

Табиғи сүт өнімдері мен қазақы тағамдардың онлайн дүкенінің веб-демо нұсқасы. Дизайны мен тауарлары Figma файлынан алынған.

- `index.html` — барлық экрандар (қош келдіңіз, басты бет, санаттар, тауар, пайдасы, себет, тапсырыс беру, тапсырыстарым, таңдаулылар, іздеу, профиль)
- `data.js` — санаттар мен тауарлар (атауы, көлемі, бағасы)
- `benefits.js` — «Пайдасы» беттерінің мәтіндері
- `img/` — суреттер
